# libbitcoin Homebrew tap

Homebrew formulae for [libbitcoin](https://libbitcoin.org), from the signed
release builds of each project, for macOS 13.3 or later on Apple silicon or
Intel.

| Formula | Installs | Command |
| ------- | -------- | ------- |
| `libbitcoin-server` | Bitcoin Server (`bs`) | `brew install libbitcoin/tap/libbitcoin-server` |
| `libbitcoin-explorer` | Bitcoin Explorer (`bx`) | `brew install libbitcoin/tap/libbitcoin-explorer` |

`brew upgrade` installs new releases. Formulae are updated by the Distribute
Release workflow of each project.
